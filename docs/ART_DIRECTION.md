# Echo Escape: the notebook

Warm paper, graphite, a red coat, and faded colored ink. The world is a sketchbook of small attempts at escape. Handwritten accents use Caveat; controls and menus use Lora.

The shared drawing helpers keep irregular outlines stable instead of adding random flicker. Platforms use graphite hatching. Crates are paper parcels. Closed doors use red crossbars and a keyhole; open doors leave dotted green edges. Pressure plates change both color and symbol. Recording slips combine numbers, words, and marks so their meaning does not depend on color alone.

The top right contains only the chamber picker and the three recording slips. The three echo colors match their recording slips. The live character wears a red coat and ochre scarf. Echoes have an additional ring over their heads. Scarf movement, walking feet, and landing squash are visual only.

All 20 chamber layouts, collision shapes, physics, inputs, recording rules, puzzle sequences, and audio are preserved. Presentation is attached when a chamber loads. The project includes both fonts locally and their SIL Open Font License notices in the font assets directory. No network access is needed to play.

Run the game normally from Godot. Run `python3 tests/run_all.py` to check the game and all 20 solutions.
